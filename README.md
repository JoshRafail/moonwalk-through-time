# Moonwalk Through Time

Build a single-screen, full-screen museum experience for visitors in middle school and up. The core interaction links a lunar-history timeline to a swipeable media carousel: selecting a date changes the featured media, while swiping the media updates the selected event. A tap opens a larger view with a description and volume control. When visitors are away, attract mode advances through the content; activity should return the experience to visitor control. The aesthetic will be a clean and metal themed for pieces of the interface like the framing around the media.
